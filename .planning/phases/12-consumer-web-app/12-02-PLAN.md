  <action>
Create `frontend/web/src/pages/consumer/ListsPage.tsx` with full shopping list management.

**State:**
- `lists: ShoppingList[]` — fetched on mount
- `loading: boolean` — spinner during API calls
- `creating: boolean` — modal open state
- `newListName: string` — controlled input in modal

**On mount:** call `listService.getLists()` and set lists state.

**UI structure:**
```
<Typography.Title level={3}>Mis Listas</Typography.Title>
<div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', marginBottom: 16 }}>
  <Typography.Text type="secondary">{lists.length} lista(s)</Typography.Text>
  <Button type="primary" icon={<PlusOutlined />} onClick={() => setCreating(true)}>Nueva lista</Button>
</div>

{loading ? <Spin /> : lists.length === 0 ? <Empty description="No tienes listas aún" /> :
  <List
    dataSource={lists}
    renderItem={(list) => (
      <List.Item
        key={list.id}
        actions={[
          <Button type="text" icon={<EditOutlined />} onClick={() => navigate(`/app/lists/${list.id}`)}>Abrir</Button>,
          <Popconfirm title="¿Eliminar esta lista?" onConfirm={() => handleDelete(list.id)}>
            <Button type="text" danger icon={<DeleteOutlined />}>Eliminar</Button>
          </Popconfirm>,
        ]}
      >
        <List.Item.Meta
          title={<Link to={`/app/lists/${list.id}`}>{list.name}</Link>}
          description={`${list.items?.length ?? 0} artículo(s) · ${list.is_archived ? 'Archivada' : 'Activa'}`}
        />
      </List.Item>
    )}
  />
}

<Modal title="Nueva lista" open={creating} onOk={handleCreate} onCancel={() => setCreating(false)} confirmLoading={loading}>
  <Input placeholder="Nombre de la lista" value={newListName} onChange={(e) => setNewListName(e.target.value)} onPressEnter={handleCreate} />
</Modal>
```

**handleCreate:** call `listService.createList(newListName)`, prepend result to lists state, close modal, clear input. Show `message.error` on failure.

**handleDelete(id):** call `listService.deleteList(id)`, filter list from state. Show `message.error` on failure.

Include a "Plantillas" secondary button linking to `/app/templates`.

Full TypeScript types — no `any`. Import only from `antd`, `react-router-dom`, `../../../api/listService`, `../../../types/consumer`, and standard React.

**ListDetailPage (`frontend/web/src/pages/consumer/ListDetailPage.tsx`):**

Read `listId` from `useParams()`. Fetch `listService.getList(listId)` on mount. Display list name as page title.

**State:**
- `list: ShoppingList | null`
- `loading: boolean`
- `addingItem: boolean` — inline or modal form visible
- `newItemName: string`
- `newItemQty: number` — default 1

**Item list:** render each item as a row with:
- `Checkbox` bound to `item.is_checked` — on change calls `listService.updateItem(listId, item.id, { is_checked: !item.is_checked })` then updates local state
- Item name text (strike-through style when is_checked)
- Item quantity badge
- Delete button (Popconfirm) → `listService.deleteItem(listId, item.id)` → remove from local state

**Add item form (shown inline below the list):**
```tsx
<Space.Compact style={{ width: '100%', marginTop: 16 }}>
  <Input placeholder="Nombre del artículo" value={newItemName} onChange={(e) => setNewItemName(e.target.value)} />
  <InputNumber min={1} value={newItemQty} onChange={(v) => setNewItemQty(v ?? 1)} style={{ width: 80 }} />
  <Button type="primary" icon={<PlusOutlined />} onClick={handleAddItem}>Añadir</Button>
</Space.Compact>
```
`handleAddItem`: call `listService.addItem(listId, { name: newItemName, quantity: newItemQty })`, prepend result to `list.items`, clear inputs.

**Optimizer button:** prominent `Button type="primary"` labelled "Optimizar ruta" at top-right of page. On click: `navigate(\`/app/lists/${listId}/route\`)`.

**Back link:** `<Link to="/app/lists">← Mis listas</Link>` at page top.

**Save as template button:** secondary action "Guardar como plantilla" — on click opens a small Modal asking for template name, then calls `listService.saveAsTemplate(listId, templateName)` and shows `message.success('Plantilla guardada')`.

All state updates are local (optimistic) — no re-fetch after each action.
