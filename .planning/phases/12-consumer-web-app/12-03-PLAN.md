Create `frontend/web/src/pages/consumer/RoutePage.tsx`.

**Route params:** `listId` from `useParams()`.

**Behavior on mount:**
1. Try `navigator.geolocation.getCurrentPosition(...)` to get user coordinates. If denied or unavailable, use default coords (lat: 37.3886, lng: -5.9823 — Seville city center) with a visible warning Note.
2. Call `optimizerService.optimize({ shopping_list_id: Number(listId), lat, lng })`.
3. Store result in `result: OptimizeResponse | null` state.

**Loading state:** display `<Spin tip="Optimizando ruta..." size="large" />` centered while the request is in flight.

**Error state:** if the API call fails (catches error), display `<Alert type="error" message="No se pudo optimizar la ruta" description="Comprueba que la lista tiene artículos y hay tiendas en el radio configurado" />` with a "Volver" button.

**Result UI:**
```
<Typography.Title level={3}>Ruta optimizada</Typography.Title>

  <Col><Statistic title="Distancia total" value={result.total_distance_km} precision={1} suffix=" km" /></Col>
  <Col><Statistic title="Tiempo estimado" value={result.estimated_time_minutes} suffix=" min" /></Col>

{result.route.map((stop, index) => (

    <Typography.Text type="secondary">{stop.distance_km.toFixed(1)} km · {stop.time_minutes} min</Typography.Text>

  </Card>
```

|----------|-------------|
| browser geolocation → optimize request | User coordinates sent to backend optimizer |
| user input → product proposal | Free-text user input sent to backend |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-07 | Information Disclosure | User geolocation in optimize request | accept | Geolocation is necessary for distance calculation; user explicitly grants browser permission; coordinates not stored client-side beyond the request |
| T-12-08 | Tampering | Product proposal free-text fields | mitigate | Backend validates and sanitizes all fields; React JSX escapes output; no exec of proposal content on client |
| T-12-09 | Denial of Service | Search input debounce bypass | mitigate | 300 ms debounce on query input prevents rapid-fire API calls; backend has rate limiting per ADR |
</threat_model>
