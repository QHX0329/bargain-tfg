  <files>frontend/web/src/pages/consumer/AssistantPage.tsx</files>
  <action>
Create `frontend/web/src/pages/consumer/AssistantPage.tsx`.

**State:**
- `messages: ChatMessage[]` — conversation history, starts empty
- `input: string` — controlled text input
- `sending: boolean` — true while API call is in flight

**handleSend:**
1. If `input.trim()` is empty or `sending` is true, return early.
2. Create `userMessage: ChatMessage = { role: 'user', content: input.trim() }`.
3. Append to `messages`.
4. Clear `input`.
5. Set `sending = true`.
6. Call `assistantService.chat([...messages, userMessage])` (send full history).
7. On success: append `{ role: 'assistant', content: response.content }` to `messages`.
8. On error: `message.error('El asistente no está disponible')`.
9. Set `sending = false`.

**UI layout:**
```
<div style={{ display: 'flex', flexDirection: 'column', height: 'calc(100vh - 200px)' }}>
  <Typography.Title level={3}>Asistente IA</Typography.Title>
  <Typography.Text type="secondary" style={{ marginBottom: 16 }}>
    Consulta sobre precios, recetas, ahorro en la compra y recomendaciones de supermercado.
  </Typography.Text>

  {/* Message history — scrollable */}
  <div style={{ flex: 1, overflowY: 'auto', padding: '8px 0' }} ref={messagesEndRef_container}>
    {messages.length === 0 && (
      <Empty description="Haz tu primera pregunta sobre la compra" />
    )}
    {messages.map((msg, idx) => (
      <div key={idx} style={{
        display: 'flex',
        justifyContent: msg.role === 'user' ? 'flex-end' : 'flex-start',
        marginBottom: 12,
      }}>
        <div style={{
          maxWidth: '70%',
          padding: '10px 16px',
          borderRadius: msg.role === 'user' ? '18px 18px 4px 18px' : '18px 18px 18px 4px',
          background: msg.role === 'user' ? '#5f5e5e' : '#f0f0f0',
          color: msg.role === 'user' ? '#fff' : '#333',
          whiteSpace: 'pre-wrap',
        }}>
          <Typography.Text style={{ color: 'inherit' }}>{msg.content}</Typography.Text>
        </div>
      </div>
    ))}
    {sending && (
      <div style={{ display: 'flex', justifyContent: 'flex-start', marginBottom: 12 }}>
        <Spin size="small" style={{ marginLeft: 8 }} />
      </div>
    )}
    {/* Scroll anchor */}
    <div ref={scrollAnchorRef} />
  </div>

  {/* Input row */}
  <div style={{ display: 'flex', gap: 8, paddingTop: 16, borderTop: '1px solid #ece7df' }}>
    <Input.TextArea
      value={input}
      onChange={(e) => setInput(e.target.value)}
      onKeyDown={(e) => { if (e.key === 'Enter' && !e.shiftKey) { e.preventDefault(); handleSend(); }}}
      placeholder="Escribe tu consulta... (Enter para enviar, Shift+Enter para nueva línea)"
      autoSize={{ minRows: 1, maxRows: 4 }}
      disabled={sending}
      style={{ flex: 1 }}
    />
    <Button type="primary" icon={<SendOutlined />} onClick={handleSend} loading={sending} disabled={!input.trim()}>
      Enviar
    </Button>
  </div>
</div>
```

**Auto-scroll:** use `useRef` for the scroll anchor div. In a `useEffect` watching `messages`, call `scrollAnchorRef.current?.scrollIntoView({ behavior: 'smooth' })`.

Import `SendOutlined` from `@ant-design/icons`. All types from `../../../types/consumer`. No `any`. Export `AssistantPage` as default.

<task type="auto">
  <name>Task 2: Implement OCRPage — file upload and item import</name>
  <files>frontend/web/src/pages/consumer/OCRPage.tsx</files>
  <action>
Create `frontend/web/src/pages/consumer/OCRPage.tsx`.

**State:**
- `file: File | null` — selected image file
- `previewUrl: string | null` — object URL for preview
- `processing: boolean` — true while OCR call is in flight
- `items: OCRItem[]` — result from OCR
- `lists: ShoppingList[]` — fetched from listService for the "add to list" selector
- `selectedListId: string | null` — which list to add items to
- `addingToList: boolean` — loading state for add-all action
- `addedItemIds: Set<number>` — track which matched_product_ids have been added (disable button after)

**On mount:** fetch `listService.getLists()` to populate the list selector.

**File selection:** use Ant Design `Upload.Dragger` with `beforeUpload` returning `false` (prevents auto-upload). In `onChange` handler, read `info.file.originFileObj` as a `File`, store in state, and create an object URL for preview with `URL.createObjectURL(file)`.

**handleProcess:**
1. If `!file`, return.
2. Set `processing = true`.
3. Call `ocrService.processImage(file)`.
4. On success: set `items = response.items`.
5. On error: `message.error('Error al procesar la imagen')`.
6. Set `processing = false`.

**handleAddAll:** for each item in `items` that has `matched_product_name`, call `listService.addItem(selectedListId, { name: item.matched_product_name ?? item.raw_text, quantity: item.quantity || 1 })`. Show progress with `addingToList = true`. On complete: `message.success(\`${count} artículo(s) añadidos\`)`.

**UI structure:**
```tsx
<Typography.Title level={3}>Escanear Ticket o Lista</Typography.Title>
<Typography.Text type="secondary" style={{ marginBottom: 24, display: 'block' }}>
  Sube una foto de tu ticket de compra o lista manuscrita para extraer los artículos automáticamente.
</Typography.Text>

{/* Upload area */}
<Upload.Dragger
  name="image"
  accept="image/*"
  multiple={false}
  showUploadList={false}
  beforeUpload={() => false}
  onChange={(info) => {
    const f = info.file.originFileObj as File | undefined;
    if (f) {
      setFile(f);
      setPreviewUrl(URL.createObjectURL(f));
      setItems([]);  // reset previous results
    }
  }}
  style={{ marginBottom: 16 }}
>
  <p><InboxOutlined style={{ fontSize: 48, color: '#5f5e5e' }} /></p>
  <p>Haz clic o arrastra una imagen aquí</p>
  <p><Typography.Text type="secondary">JPG, PNG, HEIC — máximo 10 MB</Typography.Text></p>
</Upload.Dragger>

{/* Image preview */}
{previewUrl && (
  <div style={{ marginBottom: 16 }}>
    <img src={previewUrl} alt="Vista previa" style={{ maxHeight: 200, borderRadius: 8 }} />
  </div>
)}

{/* Process button */}
<Button
  type="primary"
  icon={<ScanOutlined />}
  onClick={handleProcess}
  loading={processing}
  disabled={!file}
  style={{ marginBottom: 24 }}
>
  Procesar imagen
</Button>

{/* Results */}
{items.length > 0 && (
  <>
    <Typography.Title level={4}>Artículos detectados ({items.length})</Typography.Title>
    <Table
      dataSource={items}
      rowKey={(_, idx) => String(idx)}
      pagination={false}
      size="small"
      columns={[
        { title: 'Texto original', dataIndex: 'raw_text' },
        { title: 'Producto detectado', dataIndex: 'matched_product_name', render: (v?: string) => v ?? <Tag color="orange">Sin coincidencia</Tag> },
        { title: 'Cantidad', dataIndex: 'quantity' },
        { title: 'Confianza', dataIndex: 'confidence', render: (v: number) => `${Math.round(v * 100)}%` },
      ]}
      style={{ marginBottom: 16 }}
    />

    {/* Add to list */}
    <Space wrap>
      <Select
        placeholder="Selecciona una lista"
        value={selectedListId}
        onChange={setSelectedListId}
        style={{ width: 240 }}
        options={lists.map((l) => ({ value: l.id, label: l.name }))}
      />
      <Button
        type="primary"
        onClick={handleAddAll}
        loading={addingToList}
        disabled={!selectedListId || items.filter((i) => i.matched_product_name).length === 0}
      >
        Añadir artículos detectados a la lista
      </Button>
    </Space>
  </>
)}
```

Import `InboxOutlined, ScanOutlined` from `@ant-design/icons`. All types from `../../../types/consumer`. No `any`. Export `OCRPage` as default.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user file → OCR backend | User-supplied binary image sent to /ocr/process/ |
| assistant messages → LLM backend | User input sent to Gemini proxy at /assistant/chat/ |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-13 | Tampering | Malicious image file upload | mitigate | frontend accepts only image/* MIME types via accept attribute; backend validates file type and size before passing to OCR; no client-side execution of image content |
| T-12-14 | Denial of Service | Large image file | mitigate | UI note says max 10 MB; backend enforces server-side size limit; no client-side processing of image data |
| T-12-15 | Information Disclosure | Full chat history sent each request | accept | Chat history is session-local (component state); not persisted to localStorage; cleared on page navigation; backend only stores for LLM context window, not user-attributed |
| T-12-16 | Injection | User chat messages containing prompt injection | accept | Backend LLM has system prompt guardrails per CLAUDE.md rule 7; client sends raw text — no sanitization needed as backend is the injection boundary |
</threat_model>
