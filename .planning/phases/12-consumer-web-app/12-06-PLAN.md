Backend API endpoints:
- GET /users/profile/ → UserProfile
- PATCH /users/profile/ → UserProfile (accepts first_name, last_name, email)
- POST /auth/change-password/ → body: { current_password, new_password, new_password_confirm }
- GET /optimizer/config/ → OptimizerConfig
- PATCH /optimizer/config/ → OptimizerConfig (accepts partial fields)
- GET /notifications/?page={n} → { count, next, previous, results: Notification[] }
- PATCH /notifications/{id}/mark_read/ → Notification
- POST /notifications/read-all/ → void
- GET /prices/alerts/ → PriceAlert[]
- POST /prices/alerts/ → PriceAlert (body: { product: productId, target_price, store? })
- DELETE /prices/alerts/{id}/ → void

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /users/profile/ | User profile data read and written |
| browser → /auth/change-password/ | Password change — sensitive credential operation |
| browser → /prices/alerts/ | Alert creation with product ID and price threshold |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-17 | Spoofing | Change password form | mitigate | current_password field required; backend verifies against stored hash before accepting new password; Input.Password masks input; form sends over HTTPS |
| T-12-18 | Information Disclosure | Profile data in consumerAuthStore | accept | Store holds only profile metadata (no credentials); cleared on logout via navigate('/login'); no sensitive fields (password hashes) in UserProfile type |
| T-12-19 | Tampering | Optimizer weight sliders | accept | Sliders bounded 0–100 client-side; backend validates w_precio + w_distancia + w_tiempo sum and individual range before applying; client sum hint is informational only |
| T-12-20 | Elevation of Privilege | Price alert creating alerts for any product ID | accept | Backend enforces user ownership — DELETE /prices/alerts/{id}/ returns 403 if not owner; POST validates product ID exists; client only exposes alerts belonging to the authenticated user |
</threat_model>
