# Capturas de la memoria (Cap. 9 y Cap. 10)

Este directorio contiene las capturas usadas en la memoria del TFG.

**Cómo insertar una captura (memoria LaTeX):** deja el PNG en esta carpeta con el nombre indicado
y, en `Capitulos/cap09.tex`, sustituye la línea `\capturaPendiente[<ancho>]{<archivo>}` por la
línea `\includegraphics[width=<ancho>\textwidth]{diagramas/capturas/<archivo>}` que ya está
justo encima, comentada. El documento compila aunque falten capturas (se muestra un hueco
`[CAPTURA PENDIENTE]`).
